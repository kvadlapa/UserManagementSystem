Type Casting:
Implicit Type Casting: Low sige compatable types to big size(byte to int)
Explicit: Big to Small(Int -> byte)
int i=1;
byte j = i;// Not possible. error thrown
byte j = (byte) i; //Explicit type conversion/type casting

Non Compatable types:
String —> int(Not Compatable)

string str = “1”;
int i = int.parse(str);
or
int j = Convert.toInt32(str);
